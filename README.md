# Python Data Analysis Practice

A practical data analysis project covering **NumPy, Pandas, data cleaning, outlier detection, time series analysis, and data visualization** using multiple real-world datasets.

## Overview

This repository contains a complete Python data analysis assignment designed to build practical skills in numerical computing, data manipulation, statistical analysis, data cleaning, and visualization.

The project uses popular Python libraries such as **NumPy, Pandas, Matplotlib, and Seaborn** to analyze datasets including restaurant tips, Titanic passengers, Iris flowers, Superstore sales, Delhi climate, UCI Adult Census, diabetes data, and house prices.

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/python-data-analysis-practice.git
```

### 2. Open the notebook

Open:

```text
python_data_analysis.ipynb
```

using Jupyter Notebook, JupyterLab, VS Code, or Kaggle.

### 3. Install required libraries

```bash
pip install numpy pandas matplotlib seaborn
```

### 4. Run the notebook

Run the notebook cells from top to bottom.

> Dataset paths may need to be updated depending on whether the notebook is executed on Kaggle, Jupyter Notebook, or locally.
